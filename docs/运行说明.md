## 1. 交付物与目录结构

```
/app/
├── harness.py              # 三入口的总入口（describe / train / predict）
├── contest_submission.py   # 协议实现：读帧、调度、写帧
├── contest_loop.py         # 策略层：动作选择、评估门、经验累积
├── c_regime.py             # C 包：按工况分段标准化 + 300 轮续训（含最优轮回滚与塌陷护栏）
├── c_long.py               # 早期的 900 轮版本（保留作对照，当前不使用）
├── net.py                  # 纯 NumPy 前向（推理期唯一计算路径）
├── checkpoints/
│   ├── A.npz               # A 包起点（官方父检查点续训产物，steps 240）
│   ├── B.npz               # B 包起点（官方父检查点原样，steps 825）
│   └── C.npz               # C 包起点（官方父检查点续训产物，steps 55250）
├── baselines/
│   ├── model.py            # 官方模型与 checkpoint 读写（未改）
│   ├── data.py             # 官方特征解析（未改）
│   ├── train.py            # 官方训练器（未改，保留作为默认路径）
│   └── configs/{A,B,C}.json# 与父检查点一致的 task/宽度/超参
└── contest_harness/        # 平台 SDK（未改）
```

## 2. 运行环境

| 项 | 要求 |
|---|---|
| 容器 | Docker / OCI，镜像内 **Python 3.11** |
| 依赖 | 仅 `numpy`（镜像内置，无需联网安装；`requirements.txt` 已锁版本） |
| 网络 | **完全离线**。推理期零网络请求；训练期的模型调用只能走宿主提供的 `host_gateway_rpc` |
| 正式评测资源 | 2 核 / 4 GiB / 临时磁盘 10 GiB |
| 试运行资源 | 16 核 / 32 GiB / `/workspace` 22 GiB |
| 人工干预 | **零**。describe/train/predict 全自动，无交互提示 |

镜像构建方式（离线）：

```bash
docker build --network none -t zhixun-harness:sdk22 -f harness_sdk/Dockerfile harness_sdk
```

## 3. 启动命令

平台按三入口逐次调用，全部通过 **stdin 读帧、stdout 写帧**（stderr 是日志通道，不影响协议）：

```bash
python3 /app/harness.py describe   # 声明协议、SDK 版本、支持的任务类型
python3 /app/harness.py train      # 每轮一次：收轮次帧 → 决策/训练/提交候选
python3 /app/harness.py predict    # 逐行收样本 → 逐行输出预测
```

本地手工试跑：

```bash
docker run --rm -i zhixun-harness:sdk22 describe
```

`describe` 的正常返回：

```json
{"protocol":"contest.harness.workspace.v2","model_access":"host_gateway_rpc",
 "sdk":"contest_harness","sdk_version":"1.0.2",
 "tasks":["classification","regression"]}
```

## 4. 配置参数

### 4.1 数据包配置（`baselines/configs/*.json`）

| 包 | task | 特征 | 隐藏层 | 说明 |
|---|---|---|---|---|
| A | classification（6 类） | 128 维 | 32 | UCI gas 传感器 |
| B | regression（`target_unit: minutes`） | 34 维 | 24 | XJTU-SY 轴承 RUL |
| C | regression | 24 维 | 32 | C-MAPSS 发动机 RUL |

**这三份配置必须与父检查点一致**（task / paths / classes / hidden），否则续训会报
`checkpoint task, profile, feature schema or classes do not match`。

### 4.2 策略层参数（`contest_loop.py`）

| 参数 | 值 | 含义 |
|---|---|---|
| `ACTIONS` | `noop / retrain_20 / retrain_10 / retrain_300 / c_long` | 动作空间 |
| `EPOCHS` | `retrain_10=10, retrain_20=20, retrain_300=300, c_long=900` | 每个动作的续训轮数 |
| `B` | `retrain_20` / `retrain_10` → `noop` | B 只做官方 MSE 常规续训，固定验证集没变好就回退 |
| `GATEWAY_ATTEMPTS` | 3 | 模型网关 5xx 的最大尝试次数 |
| `_beyond_noise` | A 包 bootstrap SE ≈ 1.3pp | 判定"有效提升"的噪声带 |
| `min_pred_std` | 1.0 | C 包塌陷护栏阈值（预测标准差低于此值即拒收） |

### 4.3 环境变量

| 变量 | 用途 | 默认 |
|---|---|---|
| `CONTEST_ARTIFACT_PATH` | 本轮父产物路径（平台注入） | 回退 `/app/checkpoints/<key>.npz` |
| `CONTEST_DATA` / `CONTEST_IMAGE` | 本地复现工具用 | 无 |

## 5. 输入输出

### 5.1 输入（每行一个 JSON）

- A：`{"sample_id": ..., "features": [128 个浮点数]}`
- B：`{"sample_id": ..., "features": [34 个浮点数]}`
- C：`{"sample_id": ..., "features": [24 个浮点数]}`

训练帧由平台下发（含轮次号、父产物元信息、验证集指标接口），格式由 SDK 定义，本程序不解析原始标签文件。

### 5.2 输出（每行一个 JSON）

```json
{"sample_id": "...", "prediction": 123.45}
```

A 包输出类别下标（0–5），B/C 包输出 RUL 数值（分钟 / 循环数），且截断到非负。

## 6. 离线运行方式

1. 镜像内**没有任何外网依赖**：模型权重、特征均值方差、超参全部烘焙在 `checkpoints/*.npz` 与 `configs/*.json` 里；
2. 推理期 `predict` 只做 `clip((x−mean)/scale) → tanh → linear`，纯 NumPy，不读标签、不拟合任何统计量；
3. 训练期若需调用大模型（协议硬要求每轮至少一次），只经宿主提供的 RPC 通道，不发 HTTP；
4. 断网环境下可直接 `docker run --network none` 复现。

## 8. 异常处理

| 异常 | 处理 |
|---|---|
| 模型网关 5xx / 超时 / 连接重置 | 最多 3 次尝试，间隔 2 s、5 s；仍失败则回退规则动作并如实记录 |
| 鉴权失败（401/403/400） | 不重试，立即回退规则动作并写 `fatal` |
| 空回复 | **不重试**，按"模型未给出有效选择"处理，采用规则候选 |
| 候选权重缺失 | 直接 `RuntimeError`，**不写占位文件**、不提交空权重 |
| 提交失败 | 只试一次，失败如实上报，不换文件重试 |
| 训练塌成常数（C） | 护栏判定 `pred_std < 1.0` → 本轮拒收，交回上一轮最优 |
| 验证集变差 | `_better()` 拒收，交回上一轮最优 |
| 历史校验失败 | 按 `HISTORY_INVALID` 抛出，不吞异常 |

日志全部走 stderr（`isolate_stdio()` 保证不与协议帧混流），每轮打印：
`decide action=… reason=…` / `train action=… rung=… wd=… epochs=… before=… after=… accepted=…`。

## 10. 常见故障定位

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `MODEL_CALL_REQUIRED` | 本轮没有任何成功的模型调用 | 检查网关与 `ask_model` 是否被短路 |
| `HISTORY_INVALID` | 轮次历史校验失败（丢轮/重放） | 检查上一轮是否异常退出 |
| `checkpoint ... do not match` | 配置与父检查点 task/classes/hidden 不一致 | 核对 `configs/*.json` |
| `resume hidden width must match` | 改了隐藏层宽度 | 恢复原宽度（A 32 / B 24 / C 32） |
| 预测输出为空 | 输入帧格式不符 / 提前退出 | 看 stderr 最后 20 行 |
| 试运行超时 | 2 核环境下单轮训练过长（实测 C 300 轮约 2,300–4,000 秒） | 回滚到 sdk21 |
