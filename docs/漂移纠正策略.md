# 漂移纠正策略（一页复习版）

> 写给人看，不是规范文档。想快速回忆"我们的系统到底在干什么"，看这一份就够。
> 代码实现见 `src/monitor.py` / `src/attribute.py` / `src/policy.py` / `src/actions.py`。
>
> ⚠️ **边界（2026-11-11 补）**：本文描述的是**旧系统（按数据窗在线决策）**的设计与实测。官方包到手后，任务的时钟从"数据窗"改成了"训练轮"，推理进程是纯前向、没有状态钩子（`baselines/predict.py:1` "no model execution hooks"）。
> 所以：**这里的思想全部保留，但"动作发生在哪一刻"变了**——`calibrate` 不可能在推理时临时调阈值，只能提前烘进权重（改输出偏置或类别先验）；`rollback` 也不可能在推理时回退，只能"这一轮不采用、留旧检查点"。
> 记结论时请连同这句一起记，否则会以为我们能在评测时现场改模型。

## 一句话

**不按"漂移类型"选动作，按"证据强度"选动作；每个动作都要过安全闸，动完还要考试，考砸就回滚。**

## 一、五环各管什么

| 环节 | 回答的问题 | 输入 | 输出 |
|---|---|---|---|
| **监测** | 漂没漂？ | 当前窗数据 + 冻结基线模型 | `level`（0/1/2） |
| **归因** | 是哪种漂？ | 两条 PSI + 延迟标签 | `drift_type`（none/covariate/concept/mixed） |
| **决策** | 动不动？动哪个？ | 上面两个 + 预算 + 冷却 | `action` + `reason` |
| **执行** | 怎么动？ | action | 新模型 / 新阈值 / 回滚 |
| **评估** | 动完好不好？ | 上一窗 vs 本窗 | 接受 / 拒绝 |

关键设计：**监测器绝不看被监测模型自己的预测**（`pred_psi` 用冻结基线算），否则模型一错，监测器跟着瞎。

## 二、四个动作

| 动作 | 干什么 | 成本 | 什么时候用 |
|---|---|---|---|
| `none` | 什么都不做 | 0 | 默认；拿不准也选这个 |
| `calibrate` | 只挪判定阈值，不动权重 | 极低 | 单侧轻警；排序没坏只有分数偏了 |
| `retrain` | 滑窗重训，换一个新模型 | 中（约 0.3s） | 判断边界变了 |
| `rollback` | 回退到漂移前的快照 | 低 | 警报解除后恢复；或确认自己调坏了 |

**注意**：`calibrate` 只改"及格线"，`retrain` 改"怎么判断"。这两件事不能互相替代。

## 三、监测：怎么判"漂了"

三个证据，任一达到阈值就升级：

1. **输入侧 PSI**（`feat_psi_max`）：12 个特征里最大的那个分布偏移。>0.10 轻警，>0.25 重警
2. **输出侧 PSI**（`pred_psi`）：模型输出分数的分布偏移。用冻结基线算，不受当前模型影响
3. **延迟标签**：上一窗的真实 F1 / AUC / ECE（标签晚一窗到）

分级：
- 都低于 0.10 → `level 0`（不报）
- 任一 ≥ 0.10 → `level 1`（轻警）
- 双侧都 ≥ 0.25（或综合分超阈值）→ `level 2`（重警）

## 四、归因：怎么判"哪种漂"

看**两条 PSI 的比值**，不是看绝对值：

```
ratio = pred_psi / max(feat_psi_max, 1e-9)
```

| 条件 | 判定 | 含义 |
|---|---|---|
| 两条都 < 0.10 | `none` | 没漂 |
| `pred_psi ≥ 0.25` 且 `ratio ≥ 1.5` | `concept` | 输入没怎么变，输出变了 → 判断标准变了 |
| `ratio ≥ 1.0` 且两侧 ≥ 0.10 | `mixed` | 两边都在变 |
| `feat ≥ 0.10` 其余 | `covariate` | 输入变了，但判断规律没变 |

依据：实测纯协变量漂移 ratio 在 0.2–0.4，概念漂移在 2.3–3.0，两者不重叠。

**为什么不用绝对值**：B 段输入 PSI 冲到 0.75，但输出 PSI 只有 0.14——只看绝对值会误判成 mixed，实际是纯协变量。

## 五、决策表（当前版本）

从上到下匹配，命中即返回：

| 顺序 | 条件 | 动作 | 理由 |
|---|---|---|---|
| 1 | 预算剩余 < 15% | `none` | 安全闸，最高优先级 |
| 2 | 重训次数 ≥ 6 | `none` | 防无限自我迭代 |
| 3 | `level == 0` | `none` | 没报警 |
| 4 | `level == 1` | `calibrate` | 先做零成本动作（有 2 窗冷却） |
| 5 | `level == 2` + 冷却中 | `none` | 冷却期 |
| 6 | `level == 2` + `covariate` | `retrain` | 警报级尺度偏移，只校准救不回来 |
| 7 | `level == 2` + `concept`/`mixed` | `retrain` | 判断边界失效 |
| 8 | 触发了 F1 兜底（可选开关） | `calibrate` | 默认关闭 |

**第 6 条是改过的**：原规则"协变量 → 只校准"，其实错了。B 段 w8 实测：校准 0.818、重训 0.968。

## 六、五道安全闸

| 闸 | 参数 | 作用 |
|---|---|---|
| 预算闸 | 剩余 < 15% | 见底就停手 |
| 次数闸 | 重训 ≥ 6 次 | 防自我迭代失控 |
| 校准冷却 | 2 窗 | 防频繁挪线 |
| 重训冷却 | 2 窗 | 防每窗都重训 |
| **评估门** | 退步 > 0.005 就拒绝 | 动完要考试，考砸不接受 |
| **基线守护** | 比冻结基线差 0.02 就回滚 | 兜底 |

## 七、实测成绩（3 seed 均值，`docs/experiments.md:68`）

| 策略 | 全程 F1 | 相对基线 | 恢复段 |
|---|---|---|---|
| A 冻结（什么都不做） | 0.8065 | — | 0.814 |
| C 滑窗重训，无回滚 | 0.7067 | −10.0pp | 0.180 |
| **D 滑窗 + 边缘回滚（我们）** | **0.8229** | +1.64pp | 0.814 |
| E 短窗 + 回滚 | 0.8332 | +2.67pp | 0.814 |
| I 每 4 窗无脑重训 | 0.8252 | +1.87pp | 0.814 |

四段拆解（D 组）：A 0.823 → B 0.898 → **C 0.344**（掉到 0.161 再爬回）→ D 0.814。

## 八、四个反直觉结论

1. **"什么都不做"排第 4**，六种主动策略全在它下面——乱动比不动更糟。
2. **智能溢价只有 0.8pp**：E（0.8332）比"每 4 窗无脑重训"的 I（0.8252）只高 0.8pp。
3. **恢复段那一次校准值 9 个点**：D/E/I 恢复段 0.814 = 基线零损失，F/G/H 只有 0.614。区别就在"警报解除时有没有回滚 + 校准"。
4. **概念漂移段谁都要挨一刀**：所有策略 C 段起点都掉到 0.148–0.160，区别只在爬回速度（E 3 窗、D 6 窗、F/G/H 8 窗、C 永不回）。
