# A 包漂移对抗方案 v2（实测版）

> 对象：UCI #224 电子鼻漂移数据，6 类气体，10 批，128 维（16 传感器 × 8 指标）。
> 协议：第 r 轮只用 batch1..batch r 训练、只预测 batch r+1，r=1..9，得 b2..b10 共 9 个 macro-F1。与平台"逐轮发新批、从上一轮 checkpoint 续训"一致。
> 全部数字为本地实跑；脚本 `tools/a2/probe1–19.py` + `tools/a2/solution.py`（主线与参考实现）、`tools/a2_agent_dg/`（域泛化）、`tools/a2_agent_metric/`（度量学习）。未引用任何估计值。

---

## 一、结论先行

**可达**：滚动 9 批 macro-F1 均值 **0.838–0.847**，最低批 **0.691**（b2）。
**不可达**：**"每一批都 ≥0.80"在这份数据上做不到**。卡在两批数据结构性上限：

| 批次 | 最好成绩 | 原因 |
|---|---|---|
| b2 | 0.69–0.76 | Toluene 全批只有 **5 条**（0.4%），该类 F1 对 macro 均值是硬拖累，不是模型错 |
| b6 | **0.64–0.69** | Toluene 467 条中 **449 条**在表示空间里落进 Acetaldehyde 区域，最近原型判对率 **0.00**（20/20 次实验） |
| b10 | 0.72–0.76 | Acetaldehyde 600 条中 324 条被判 Ethanol |

除这三批，其余批次稳定在 0.88–0.99。

之前执行的方案停在 0.7050，差距不在"漂移算法不够花哨"，而在两件地基没做对：**逐样本稳健标准化**（+5.5pp）与**马氏白化原型头**（相对余弦原型 +9.6pp）。在这个地基上再叠域适应、评估门、伪标签，全是负收益——简报里那些 −3~−13pp 的结论我基本都复现了。

## 二、诊断：问题到底在哪

### 2.1 批内几乎完全可分，问题 100% 在跨批映射

每批用自己的标签做 5 折 CV（`tools/a2/probe7.py`）：

| 批 | b1 | b2 | b3 | b4 | b5 | b6 | b7 | b8 | b9 | b10 |
|---|---|---|---|---|---|---|---|---|---|---|
| raw | .961 | .881 | .995 | .995 | .977 | **.986** | .999 | .978 | .996 | .991 |
| robust | .987 | .922 | .996 | .990 | .977 | **.987** | .999 | .969 | .998 | .995 |

b6 内部 Toluene 召回 **1.00**，b10 内部 0.99。**数据没有坏，是同一个类在不同批次落到了特征空间的不同位置。**

这条结论决定了方向：不要去"提升特征质量"，要去"消除批次位移"。

### 2.2 漂移的尺度大于类间距离

块内方差 0.64σ；类内跨批 0.62–2.05σ；类间 0.48σ。即**同一个类的新旧样本，比不同类的样本还远。**

任何"全局对齐 / 全局重标准化 / 整体域适应"都在拿类间距离换类内距离——这就是 CORAL、均值对齐、IRM、MMD、GRL 全部无效的根本原因（实测见第五节）。

### 2.3 漂移的主成分是"批级、类无关、每通道一阶偏移 + 逐传感器乘性增益"

证据：`emp_shift`（按批均值差把样本搬到另一个已见批的位置）是唯一在**线性头**上稳定正收益的增广（5/5 种子，+1.56pp）；而各向同性高斯平移噪声（σ 0.1–0.8）全部有害（0.764–0.803）。说明增益在"平移方向要落在真实漂移子空间里"，不在加噪声。

但这条增广**与马氏头不兼容**（见 3.5），最终不采用。

### 2.4 b6 的真实机制（决定天花板）

训练 r=5 后测 b6（`tools/a2_agent_metric/diag_maha.py`）：

- 467 条 Toluene → 最近类中心：**449 条判 Acetaldehyde**。
- 到 Toluene 原型余弦 0.290±0.081；到 Acetaldehyde 原型 0.645±0.068。
- 马氏距离：到 Tol 原型 1022，到 Ace 原型 300。
- **最近原型判对率 0.00**（4 配置 × 5 种子，20/20 次全是 0.00）。

这不是分类器判错，是这批 Toluene 在嵌入空间里**整体塌进 Acetaldehyde 区域**。b1–b5 里 Toluene 一共只有 79 条，且 b3–b5 为 0——训练期从未见过"该类的 b6 工况形态"，任何标签保持增强都无法凭空造出来。

b6 若 Toluene 全错，macro-F1 结构上限是 `5/6 × 其它类水平 ≈ 0.83`；当前 0.69 说明还有约 0.14 丢在别的类上，但这需要"缺类保护/新类拒识"才能回收，且 6 类输出口径下未必能计分。

### 2.5 为什么必须用马氏白化（而不是余弦/欧氏原型）

嵌入的类内协方差谱：**top1 方向占 29.2%，top3 占 67.5%，top8 占 90.7%，条件数 487。**

少数几个方向承载了绝大部分类内方差——这几个方向就是漂移方向。余弦/欧氏把每维等权看待，类间距离被漂移方差淹没；马氏白化把这些方向压平，原型距离才可比。

同一编码器、只换分类头：余弦原型 **0.742** → 马氏原型 **0.838（+9.6pp）**。单点最大改进。

## 三、方案

四件套。全部纯 numpy、无 GPU、无新依赖、参数 < 10k。

### 3.1 特征层：逐样本稳健标准化（+5.5pp，地基）

```
med = median(x[128])            # 逐样本
mad = median(|x - med|)
z   = (x - med) / mad^2.0
```

- 只用**样本自身**的统计量，不跨样本、不用测试批分布 → 合规。
- 消掉漂移主成分（整体乘性增益 + 加性偏移），保留 16 传感器之间的相对幅度模式（气体指纹，不能丢）。
- 指数是旋钮：**配马氏头用 2.0**（更强归一化直接压掉跨批乘性增益，b6 0.66→0.69）；配线性头用 1.4。1.0 对 b6 反而掉到 0.60。
- **别用组内 z-score（sens，0.57）或组内比值（sensratio，0.75）**——它们把指纹的绝对幅度抹掉了。

### 3.2 嵌入层：32 维瓶颈 + 监督对比（SupCon）

- 投影到 32 维（d_out=32）；与 64 维均值持平（3 种子 0.847/0.659 vs 0.847/0.685，64 维最低批略高），16 维掉到 0.837。选 32 维是拿参数少换一点 b3 方差。
- SupCon：同类拉近、异类推远，温度 τ=0.1，权重 0.5；+1.4~1.9pp。
- **必须配马氏头**：配余弦 0.825，配欧氏 0.814。
- **也不能省**：干净消融（同特征、同 seed）CE+线性头 0.825、CE+马氏 0.824、SupCon+马氏 0.838。马氏头单独用几乎无增益，**必须由 SupCon 先把类条件结构塑造出来，白化才救得回来**。两件套是一组，不能拆。

### 3.3 头：马氏白化原型（最大单点）

```
proto_c  = mean(z[y == c]);  proto_c /= ||proto_c||   # 单位向量，只用训练集标签
S        = cov(z - proto_y)                           # 类内协方差 32×32
S       <- 0.5*S + 0.5*I*tr(S)/32                     # 50% 收缩到各向同性（关键，不是 1%）
Si       = inv(S + 1e-6*I)
pred     = argmin_c (z-proto_c)^T Si (z-proto_c)      # score = softmax(-d²/2)
```

- 收缩系数 **0.5** 是核心：不加收缩时 S 条件数 487，求逆基本是把噪声放大；收缩一半后漂移方向被压平但仍保留判别方向。文档早期写的"1% 迹正则"是错的，实测版本是 50% 收缩。
- 用 `inv(S)` 算二次型即可，不必真开平方求 `S^{-1/2}`（数学等价，且无开方数值问题）。
- 参数：`w1` 128×128=16384、`w2` 128×32=4096、`wc` 32×6=192、`protos` 6×32=192、`whiten/Si` 32×32=1024，合计 **22054**，远低于 100k 上限。

### 3.4 续训协议

- 每轮累积**全部**历史批重训（冻结 0.386、只留最近 1 批 0.591、只留 2 批 0.675——都更差，复核一致）。样本量比漂移新鲜度更重要。
- 从上一轮 checkpoint `--resume`，保留 Adam 一/二阶矩。
- 新批加入后重算：全部原型、协方差 S、白化 W。只用训练集（含已考完批次）标签，合规。
- 多 seed（3–5 个）概率投票，仅 +0.002，可上可不上（成本是训练时间 ×N）。

### 3.5 明确不采用的两条（虽然单独看有增益）

| 方法 | 在线性头上 | 在马氏头上 | 结论 |
|---|---|---|---|
| emp_shift（0.5×批均值差平移） | 0.844（+1.5pp，5/5 种子） | **0.807（−3.3pp）** | 负迁移：mu 差向量混着批量成分/类别构成变化，对比损失会放大它，小样本批 b3 从 .96 掉到 .80 |
| 同类跨批 mixup（Beta(0.2,0.2)） | 0.843（+0.7pp） | 未测 | 弱正，风险不明，不进主方案 |

## 五、负面结论（别再重复这些）

| 方向 | 实测 | 失败原因 |
|---|---|---|
| **批次路由**（每批一个头 + 距离软路由） | **0.313** | 每个头在自己批的几何里自洽，测试批不在任何历史批几何附近；T 从 0.25 到 2.0 结果完全不变（权重早饱和） |
| 等权/种子集成 | 0.832–0.843，无增益 | 剩余误差是系统性偏差，不是方差 |
| CORAL / 均值对齐 | 0.829 / 0.833 | 一阶矩已被 robust 削掉，残余是类条件+非线性；强行对齐二阶矩连判别方差一起压平 |
| 类条件中心对齐 | 0.768 | 把同类簇互搬到一起，抹掉类间边界（b3 .96→.61） |
| IRM / REx | 0.827 | 2–9 个域且极不均衡（b4 161 条 vs b7 3613 条），风险方差梯度被 CE 淹没 |
| GRL 批号对抗 | 0.830 | 批间均值差太大，判别器几步饱和；批号可分成份里混着类别信号 |
| RBF-MMD | 0.788–0.802 | 128 维尺度差异大，核带宽不可比；λ 大则抹掉类结构 |
| 训练先验 logit 校正 | **0.317** | 把 Toluene 这类稀有先验直接压死，方向完全反了 |
| triplet | 0.789–0.807 | 半硬负样本大多是漂移样本，等于教模型"把漂移当负例" |
| 跨批同类对齐（无白化） | 0.821–0.828 | 拉近的收益被漂移吃回去 |
| 传感器增益抖动 σ≥0.2 | 0.79–0.80 | 各向同性噪声破坏类结构；σ=0.1 的 0.8385 是单种子假象 |
| 三重变换拼接（rob+rank+sr） | 0.784 | rank 分支的噪声维度抵消增益 |
| TTA（8 次增益抖动平均） | 无变化 | 增益抖动不是不变方向 |
| 部分传感器归一化 β=0.2–0.8 | 0.754–0.822 | 任何组内归一化都在丢指纹的绝对幅度 |
| 只留最近 1/2 批训练 | 0.591 / 0.675 | 样本量比漂移新鲜度更重要 |
| 余弦原型 / 欧氏原型 | 0.742 / 0.814 | 类内方差被少数漂移方向主导，未白化 |

## 六、落地改动清单（对官方 `baselines/model.py`）

1. **`normalized()` 替换**：训练集 mean/scale → 逐样本 `(x - median) / MAD^2.0`。`save/load` 仍保留 mean/scale 字段（置 0/1）以兼容格式，保留 `np.clip(±10)`。
2. **结构扩一层**：`h = tanh(x@w1+b1)`（128→128）、`f = h@w2+b2`（128→32）、`z = f/||f||`；**新增 `wc`(32×6)/`bc`(6)** 作 CE 分类头（作用在未归一化的 `f` 上）；**新增 `protos`(6×32)/`whiten`(32×32)** 供推理。`PARAMETERS` 扩为 8 个数组，`validate()` 的 shapes、`load()` 的 npy 集合同步扩展（否则报 `checkpoint tensors missing`）。`predict` 改为 `softmax(-d²/2)`，`d_c = (z-proto_c)^T Si (z-proto_c)`。
3. **损失**：CE（label smoothing 0.1）+ SupCon（τ=0.1，权重 0.5，32 维投影）。
4. **续训**：`resume` 保留 Adam 矩；每轮末尾用全部已见批重算原型/协方差/白化。
5. **不做**：任何测试批统计、伪标签、集成、评估门。

预计改动 150–200 行，无新依赖。`hidden=128`（d_out=32），参数 **22054**，checkpoint 仍远小于 16MiB。

## 八、剩余风险

1. **b2 / b6 无法达 0.80**，这是数据上限。若评审要求"每批 ≥0.80"，需先说明 b2 的 Toluene 只有 5 条这一事实，以及 b6 的 Toluene 在表示空间整体塌陷。
