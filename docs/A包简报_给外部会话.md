# A 包任务简报（给外部会话）

> 用途：把这个文件整段贴给另一个 AI 会话，让它帮忙找漂移对抗方法。
> 写于 2026-11-16。所有数字都是实测，不是估计。

---

## 一、一句话背景

我们在做一个工业 AI 竞赛，题目是「在数据分布不断漂移的情况下，让一个模型持续保持性能」。
A 包是三个子任务之一：**用气体传感器区分六种挥发性有机物**。数据会随批次漂移，我们要在只能拿到「已经考完的批次」的前提下，预测下一批。

---

## 二、数据长什么样

### 2.1 来源与规模

- 原始数据：UCI Machine Learning Repository #224 **Gas Sensor Array Drift Dataset**（13910 条，10 个 batch，2007-01 到 2011-02 采集）
- 官方任务包只公开了前两个 batch：
  - `train` = **batch1，445 条**
  - `validation` = **batch2，1244 条**
  - 隐藏测试流 = **batch3–batch10，共 12121 条**（我们已逐条比对确认：train/val 就是原始 batch1/batch2 的完整拷贝，没打散、没抽样、没改标签）

### 2.2 特征

- **128 维**，来自 16 个传感器 × 8 个指标：
  - `ΔR`（电阻变化）、`|ΔR|`、以及 6 个不同窗口的 EMA（指数移动平均）
- 特征已经归一化过，量纲大致统一
- 没有时间戳列，**顺序就是采集顺序**

### 2.3 标签

- **6 类**：Ethanol / Ethylene / Ammonia / Acetaldehyde / Acetone / Toluene
- 评价指标是 **macro-F1**（六类等权），不是准确率

### 2.4 三个致命的形态特征

**（A）数据按类别成块，不是随机排列**

| 批次 | 条数 | 类别切换次数 | 平均块长 |
|---|---|---|---|
| batch1 | 445 | **9 次** | 49 条 |
| batch2 | 1244 | **14 次** | 89 条 |

也就是说，**你拿到连续的 100 条，大概率只包含 1–2 种气体**。
任何「按固定窗口切分再算分布差异」的做法都会失效——因为你比的是两种不同的气体，不是漂移。

**（B）类别分布剧烈变化（长尾在变形）**

| 类别 | batch1 | batch2 | batch10 |
|---|---|---|---|
| Ethanol | 20.2% | 13.2% | 16.7% |
| Ethylene | 22.0% | 26.8% | 16.7% |
| Ammonia | 18.7% | 8.0% | 16.7% |
| Acetaldehyde | 6.7% | 8.8% | 16.7% |
| Acetone | 15.7% | **42.8%** | 16.7% |
| Toluene | 16.6% | **0.4%** | 16.7% |

- batch1 头尾差 **3.3 倍**（98 vs 30）
- batch2 头尾差 **106 倍**（532 vs 5）
- 这不是「长尾样本少」，是**长尾的形状在变**

**（C）漂移是「跳变 + 回摆」，不是渐变**

相邻批次的特征分布 PSI：

| 相邻对 | PSI |
|---|---|
| b1→b2 | 0.67 |
| b3→b4 | 1.05 |
| b4→b5 | 1.58 |
| b5→b6 | **1.94** |
| b6→b7 | 0.44 |
| b7→b8 | **1.96** |
| b8→b9 | 1.27 |
| b9→b10 | 1.18 |

但**相对 batch1 的累计距离不单调**：

- b1→b5：**3.87**（最远）
- b1→b10：**0.36**（几乎回到原点）

⇒ 数据在几个状态之间**来回摆**，不是一路越变越坏。这一点很重要：**历史数据里存着将来还会再遇到的分布。**

### 2.5 三个尺度的漂移量（这是最关键的数字）

| 比较对象 | 均值位移 | 说明 |
|---|---|---|
| **块内**（同批同类，按顺序切前后半） | **0.64σ** | 同一瓶气体测久了，基线自己会爬 |
| **块间**（同类，跨批次） | **0.62–2.05σ** | Toluene 最狠 2.05σ，Ammonia 最轻 0.62σ |
| **类间**（同批，不同气体） | **0.48σ** | 不同气体之间的距离 |

**注意：类内漂移（0.62–2.05σ）> 类间距离（0.48σ）> 块内漂移（0.64σ，与类间相当）。**

这意味着：**同一种气体的旧样本和新样本，比两种不同气体的样本差得更远。**

直接后果：batch2 里 **Acetaldehyde 召回率 = 0.000**（109 条全被判成 Ethanol）。原因是 batch2 的 Ethanol 类内半径从 11.8 膨胀到 97.2、样本从 90 增到 164，**把 Acetaldehyde 整团罩住了**。

## 三、竞赛的流程与评分

### 3.1 十轮续训

- 平台分 10 轮下发数据，**每轮给一个新批次（带标签）**
- 每轮：拿新批次 → 训练 → 提交一个 `checkpoint.npz`
- **必须从官方 baseline 出发**，每轮 `--resume` 上一轮，保留父子链（`training.json` 记 `parent_checkpoint_sha256`）
- 每轮训练预算：几分钟（CPU）

### 3.2 在线推理（正式评测）

- 提交的是 **Docker 镜像**，平台逐行喂 JSONL：`{"task":"classification","inputs":{"features":[128 个数]}}`
- 输出：`{"outputs":[{"label":"Ethanol","score":0.84}, ...]}`
- 评测机：**4 核 8G、无 GPU、无外网**，镜像 ≤ 2GB

### 3.3 评分

- A 包：**macro-F1**（六类等权）
- 综合分 G = (系统指标 − 静态基线) / (参考上界 − 静态基线)
- 另有「最差阶段表现」「恢复速度」「抗遗忘（历史工况保持 ≥95%）」「资源效率（单位增益消耗的算力/token）」

## 四、硬约束（这是筛选方案的关键）

**这些约束会否掉大部分学术方法，请务必先看：**

1. **推理期绝对不能拟合任何东西。**
   官方文档原文：*「输入均值、标准差及回归目标缩放最初只在训练集拟合…验证集和隐藏集不能参与拟合这些统计量」*。
   ⇒ 阈值校准、预测分布对齐、标准化重估、TTA、伪标签、在线更新，**在推理期全部违规**。
   自进化只能体现在**十轮的训练轮**里。

2. **只能拿到「已经考完的批次」的标签。**
   第 N 轮训练时，手上有 batch1..batchN-1 的标签，要预测的是 batchN+1。**永远落后一批。**

3. **基线模型结构不能随便改。**
   `hidden` 只能在 1–128，参数 < 100000；改结构会切断 `parent_checkpoint_sha256` 父子链。

4. **没有标注预算。**
   主动学习（挑样本问人）不可用。

5. **不能联网。**
   不能用预训练大模型、不能调 API。

## 五、我们已经试过的（请不要重复推荐）

基准：官方 baseline 在 validation 上 **macro-F1 = 0.7140**。

### 5.1 能拿到新批次时

| 配方 | 8 轮滚动均值 | 相对冻结 |
|---|---|---|
| 冻结（永不更新） | 0.3859 | — |
| **累积全部历史重训** | **0.7050** | **+31.91pp** |
| 只留最近 2 批 | 0.6745 | +28.86pp |
| 只留最新 1 批 | 0.5910 | +20.51pp |

### 5.2 拿不到新批次时（8 条路，7 条负）

| 方法 | 实测 | 为什么失败 |
|---|---|---|
| **集成**（多模型投票 / 按 log n 加权 / 只取最近 3 个） | −2.8 ~ −5.5pp | 新模型已经把历史压进去了，再平均等于稀释 |
| **评估门**（分数没变好就不接受） | **−13.1pp** | 用 batchN 的分数判断 batchN+1，两者不同步 |
| **域适应 / 标准化重估** | −3.1pp | 批次放大时信号也放大，标准化把白捡的信号压回去 |
| **伪标签 / 自训练** | 比冻结还差 | 确认偏误，越学越偏 |
| **LLM 决策**（Qwen3.8-27B 看证据决定动作） | −8.5pp（0.6403 vs 规则 0.7256） | 把「该重训」误判成「该校准」 |
| **逐条距离信号**（隐层到类中心距离） | 陌生度有效（p50 1.089→2.341），错误定位失败 | 氨气最远（3.118）却全对，乙醛全错（2.681）只排第三 |
| **focal loss**（换损失函数） | 跨批 −1.3pp；同批 +20pp 但用不上 | 病根是「长尾形状在变」，不是「尾部样本少」 |
| **规则决策**（调阈值 / 判断该不该重训） | +0.46pp（噪声 ±1.3pp 内） | 不是错，是不需要判——反正每轮都要重训 |

### 5.3 为什么全负：一张矩阵

每个模型在每个批次上的 macro-F1：

| 模型 | b3 | b5 | b7 | b9 | b10 |
|---|---|---|---|---|---|
| v0（原始） | 0.594 | 0.522 | 0.327 | 0.185 | 0.381 |
| r3 | 0.825 | 0.803 | 0.644 | 0.417 | 0.442 |
| r6 | 0.827 | 0.825 | **0.997** | 0.732 | 0.698 |
| r8 | 0.830 | 0.825 | 0.994 | **0.987** | 0.695 |

- 沿列往下（换更新的模型）：单调升
- 沿行往右（换批次）：**先升后降**

⇒ **新模型在旧批次上的表现，预测不了它在新批次上的表现。** 所有「用旧数据判断要不要动」的方法都死在这里。

## 六、想请你回答的问题

**Q1｜在「只能拿已考完批次的标签」这个约束下，有没有我们没试过的、真正可行的方法？**
（注意：不能用测试数据拟合、不能改结构、不能主动学习、不能联网。）

**Q2｜乙醛被乙醇整团罩住（类间重叠度上升），除了「用上新数据重训」，还有什么在训练轮内能做的？**
我们已经试过 focal loss、类别加权、过采样，只在**同批次内**有效，跨批次无效。有没有别的思路（比如对比学习、原型网络、度量学习）能在这个约束下用？

**Q3｜「批次会回摆」这个特性（b1→b10 距离只有 0.36）有没有被利用的空间？**
我们现在只是简单地把所有历史拼起来重训。有没有更聪明的做法（比如按分布相似度选历史、或者维护多个「状态」的模型）？

**Q4｜如果只能提高 1–2pp，你会优先做什么？**
我们现在的现实是：十轮链跑完 A 包只从 0.7140 涨到 0.7210（+0.70pp，在 ±1.3pp 噪声带内）。如果有一个「确定性高、风险低」的小改进，请推荐。

## 七、怎么判断一个建议值不值得做

请用这三条自检，不满足的直接排除：

1. **它需不需要碰测试数据？**（需要 → 违规）
2. **它需不需要每次重新训练整个模型？**（需要 → 检查是否切断父子链）
3. **它的预期收益能否说过 1.3pp？**（不能 → 优先级低于「保证提交链路不崩」）
