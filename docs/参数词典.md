# 参数词典：每个特征到底在测什么

> 用途：答辩被问"这个参数是什么意思"时能一句话答上来；写报告时不要只列名字。

---

## 一、B 包：轴承振动的 17 个特征（水平 / 垂直各一份，共 34 维）

每个轴承每转一圈，传感器采 32768 个点（25.6 kHz 下约 1.28 秒）。这 17 个数字就是"把这一小段振动压成 17 个指标"。

### 1. 时域：直接看波形

| 参数 | 公式 | 大白话 | 轴承坏了会怎样 |
|---|---|---|---|
| `rms` | $\sqrt{\frac{1}{N}\sum x_i^2}$ | 振动的"平均能量"，最常用的磨损指标 | **单调上升**，最可靠的退化信号 |
| `peak` | $\max\lvert x_i\rvert$ | 一瞬间最大的那一下 | 上升，但对偶发冲击敏感 |
| `peak_to_peak` | $\max x_i - \min x_i$ | 波峰到波谷的总落差 | 上升 |
| `mean_abs` | $\frac{1}{N}\sum\lvert x_i\rvert$ | 平均振动幅度（不看方向） | 上升 |
| `kurtosis` | 四阶矩 / 标准差⁴ | **"尖不尖"**。正常振动接近正态，峭度≈3；出现冲击时变尖 | 先升（早期点蚀）后降（全面磨损） |
| `skewness` | 三阶矩 / 标准差³ | **"左右对不对称"**。正常≈0 | 故障时偏离 0 |
| `crest_factor` | peak / rms | 尖峰有多突出。**早期故障最敏感** | 早期明显上升，后期回落 |
| `shape_factor` | rms / mean_abs | 波形"胖瘦"。正弦波≈1.11 | 变化较小 |
| `impulse_factor` | peak / mean_abs | 冲击成分占比 | 早期上升 |
| `margin_factor` | peak / (mean√\|x\|)² | 对早期微弱冲击最敏感 | 早期上升最明显 |

**记法**：`rms` 看"总体有多震"，`kurtosis`/`crest_factor` 看"有没有尖锐冲击"，`margin_factor` 看"最早期的征兆"。

### 2. 频域：把波形拆成频率

| 参数 | 含义 | 大白话 |
|---|---|---|
| `spectral_centroid` | 频谱的"重心"频率 | 能量偏高频还是低频。**磨损后常往高频移** |
| `spectral_rms` | 频谱幅值的均方根 | 频域版的"总能量" |
| `spectral_kurtosis` | 频谱的峭度 | 频谱里有没有"尖峰"（对应某个特征频率） |
| `dominant_freq` | 幅值最大的那个频率 | 最主要的振动来源。**轴承故障会在特定频率出现峰值**（内圈/外圈/滚动体各有特征频率） |
| `band1_energy_0_2k` | 0–2 kHz 能量占比 | 低频段，对应转频和结构振动 |
| `band2_energy_2k_6k` | 2–6 kHz 能量占比 | 中频段，**轴承故障的典型频段** |
| `band3_energy_6k_12k` | 6–12 kHz 能量占比 | 高频段，对应早期微小冲击 |

**为什么分三个频带**：轴承不同部位的故障会在不同频段出峰。内圈故障偏中高频，外圈偏低频，滚动体在两者之间。频带能量比单个频率更稳。

### 3. 用这些参数时要注意

- **`spectral_kurtosis` 数值巨大**（15027 这种），和其他特征不在一个量级，必须标准化。
- 水平和垂直两路**不能混着看**：同一故障在两个方向的响应不同。
- 这些特征官方已经算好了（`band1` 上界 `min(12800, fs/2)`），我们**不需要自己提特征**。

## 二、A 包：气体传感器的 128 维（16 传感器 × 8 个指标）

`inputs.features` 是一个长度 128 的列表，排列是 **16 个传感器 × 8 个指标**。

| 指标 | 含义 |
|---|---|
| `ΔR` | 电阻变化量（相对基线） |
| `|ΔR|` | 绝对值 |
| 6 个 EMA | 对 ΔR 做指数移动平均，6 个不同时间尺度 |

**为什么用 EMA**：气体传感器的响应是"慢慢爬升再回落"的曲线，用不同时间窗的平滑值，相当于记录"爬得多快、到没到顶"。单一瞬时值噪声太大。

**这 128 维的问题**（我们实测的）：真正有用的只有少数几维，其余全是噪声。所以**原始 128 维做距离度量完全不行**（最近中心分类只有 0.70/0.54），但模型学出来的 32 维隐层可以（0.96/0.88）。

## 三、C 包：C-MAPSS 的 24 维（3 个工况 + 21 个传感器）

| 类别 | 数量 | 含义 |
|---|---|---|
| `settings` | 3 | 飞行高度、马赫数、油门杆角度（**工况**） |
| `sensors` | 21 | 温度、压力、转速、流量等 |

**关键**：21 个传感器里只有一部分随退化变化，其余基本是常数或噪声。而且 6 种工况下"正常值"完全不同——**同一个传感器读数，在工况 1 是正常，在工况 6 可能是异常**。这就是为什么 C 包要先按工况分组。

## 四、训练超参（`baselines/train.py --help`）

| 参数 | 默认 | 什么意思 | 调它的后果 |
|---|---|---|---|
| `--epochs` | 20 | 把所有数据看几遍 | 多了过拟合（B 包就是这样崩的） |
| `--learning-rate` | 0.05 | 每步走多大 | 大了震荡，小了学不动 |
| `--batch-size` | 16 | 一次看几条再更新 | 影响梯度噪声，通常不动 |
| `--seed` | 42 | 随机种子 | **续训时必须一致**，否则报错 |
| `--hidden` | 32 | 隐层宽度 | 上限 128，参数上限 10 万 |
| `--weight-decay` | 0 | L2 正则强度 | 防过拟合，但我们没调 |

**只有 4 个真正值得动**：`epochs`、`learning-rate`、`weight-decay`、`hidden`。

## 五、一句话总表（答辩速查）

| 被问 | 答 |
|---|---|
| RMS 是什么 | 振动的平均能量，最能反映磨损 |
| 峭度是什么 | 波形尖不尖，正常是 3，有冲击会变大 |
| 峰值因子是什么 | 峰值除以 RMS，早期故障最敏感 |
| 频谱质心是什么 | 能量集中在高频还是低频 |
| 为什么分三个频带 | 不同部位的故障在不同频段出峰 |
| 128 维是什么 | 16 个气体传感器 × 8 个指标（ΔR、\|ΔR\|、6 个 EMA） |
| 24 维是什么 | 3 个工况 + 21 个传感器 |
| 哪些超参重要 | epochs、lr、weight_decay、hidden，其余默认 |
