# A 包（UCI 气体传感器）真实漂移诊断

> 日期：2026-11-11
> 数据：`cpu-a-guide-20261110-v1`（train=445，validation=1244）
> 脚本：`.team/_probe_gas_attr.py`、`_probe_gas_diag.py`、`_probe_gas_retrain.py`、`_probe_gas_v2.py`、`_probe_gas_v3.py`、`_probe_gas_data_need.py`、`_probe_gas_typeprob.py`
> 结论：**判据用的尺子与真实数据差一个数量级；更根本的是，数据是按生产批次成块排列的，"固定窗"这个前提本身不成立。**

---

## 0. 一句话

> A 包不是"缓慢漂移的随机流"，是**按生产批次成块下发**的。用它检验我们为"固定窗 + 随机流"设计的判据，方向从一开始就偏。

---

## 0.1 数据形态：按生产批次成块（本报告最重要的发现）

### 事实

把 train 的前 40 条打出来：

```
Etha Etha Etha Etha ... （40 条全是 Ethanol，一个不差）
```

| | 条数 | 类别切换次数 | 平均块长 |
|---|---|---|---|
| batch1 | 445 | **9** | 约 49 条 |
| batch2 | 1244 | **14** | 约 89 条 |

batch1 的 100 条窗构成：

| 窗 | 里面装的是什么 |
|---|---|
| 0 | Ethanol 84 + Ethylene 16 |
| 1 | Ethylene 72 + Ammonia 28 |
| 2 | Ammonia 55 + Acetaldehyde 29 |
| 3 | Acetone 70 + Toluene 29 |
| 4 | Toluene 45 |

**每个 100 条窗几乎只含 1–2 个类别。**

### 解释

> **实际生产是按产品批次排产的。** 一批产品连续测几十次，数据自然连成一串。

这不是数据缺陷，是工业数据本来的样子。

### 后果：前面所有"按窗算"的结论全部作废

| 结论 | 状态 | 原因 |
|---|---|---|
| 13 窗判 covariate 11 / concept 1 / mixed 1 | ❌ 作废 | 比的是不同类别，不是漂移 |
| 噪声底 feat_psi_max = 2.42 | ❌ 偏高 | 也用了顺序切分 |
| 标签漂移 PSI = 1.01 | ✅ 成立 | 按整体算的，与窗无关 |
| 各类别特征偏移 0.33–1.75σ | ✅ 成立 | 类内比较，与窗无关 |
| 重训越训越差（F1 0.704→0.166） | ✅ 成立 | 与窗无关 |

## 1. 数据与考场

| 来源 | 条数 | 角色 |
|---|---|---|
| batch1 | 445 | **训练集**（官方 checkpoint 只见过它） |
| batch2 | 1244 | **验证集**（公开、带标签，能算分） |
| batch3–10 | — | **隐藏测试流**（正式评测喂的就是这个） |

官方 baseline 的 `Macro-F1 0.7140 / Acc 0.8786` 是「batch1 训练 → batch2 测试」。

**这不是"模型不好"，是"完全不做适应时的起跑线"。**

## 2. 换批次意味着什么

"批次"是 UCI 数据集按**采集时间**切的 10 段（2007-01 → 2011-02，跨 36 个月）。

### 2.1 传感器老化：同一气体，读数变了（✅ 有效证据）

以 batch1 的标准差为单位，逐类算 batch2 相对 batch1 的特征偏移：

| 类别 | n1 | n2 | 平均偏移 | 最大偏移 | >1σ 的维度 |
|---|---|---|---|---|---|
| Ethanol | 90 | 164 | **1.75σ** | **90.06σ** | 37 / 128 |
| Ethylene | 98 | 334 | 0.59σ | 7.52σ | 25 / 128 |
| Ammonia | 83 | 100 | 0.33σ | 1.61σ | 6 / 128 |
| Acetaldehyde | 30 | 109 | 0.77σ | 2.27σ | 36 / 128 |
| Acetone | 70 | 532 | 0.59σ | 1.50σ | 15 / 128 |
| Toluene | 74 | 5 | 0.23σ | 1.20σ | 1 / 128 |

全体：平均 |d| = 0.66σ，最大 11.46σ，16/128 个维度偏移超过 1σ。

**Ethanol 最大偏移 90σ**——这不是"漂移"，是个别传感器通道在这段时间基本失效了。

### 2.2 采样比例：各类测了多少次，完全不同（✅ 有效证据）

| 类别 | batch1 | batch2 |
|---|---|---|
| Ethanol | 20.2% | 13.2% |
| Ethylene | 22.0% | 26.8% |
| Ammonia | 18.7% | 8.0% |
| Acetaldehyde | 6.7% | 8.8% |
| Acetone | 15.7% | **42.8%** |
| Toluene | 16.6% | **0.4%** |

真实标签分布 PSI(batch1→batch2) = **1.0088**。

## 3. 依然成立的诊断

### 3.1 一类彻底失效

batch2 混淆矩阵：

```
真实 \ 预测      Etha  Ethy  Ammo  Acet  Acet  Tolu
Ethanol          158     5     1     0     0     0
Ethylene          32   302     0     0     0     0
Ammonia            0     0   100     0     0     0
Acetaldehyde     108     0     0     0     1     0
Acetone            0     0     0     0   528     4
Toluene            0     0     0     0     0     5
```

- **109 条 Acetaldehyde，108 条被判成 Ethanol**，召回 **0.000**
- softmax 均值：Ethanol 0.936
- 其余五类召回 0.90–1.00

### 3.2 重训救不回来

用 batch2 前 300 条（带标签）重训，剩余 944 条评估：

| 模型 | acc | Acetaldehyde 召回 |
|---|---|---|
| 冻结 checkpoint | 0.8786 | **0.000** |
| 重训后 | 0.8686 | **0.000** |

### 3.3 数据量实验：越训越差

用官方 checkpoint，batch2 前 N 条续训，剩余部分测试：

| 新数据量 | 准确率 | **宏 F1** |
|---|---|---|
| 0（冻结） | 0.875 | **0.704** |
| 100 | 0.828 | 0.520 |
| 200 | 0.842 | 0.551 |
| 300 | 0.751 | 0.340 |
| 500 | 0.827 | 0.384 |
| 800 | **0.996** | **0.166** |
| 1000 | 0.992 | 0.166 |

**800 条：准确率 99.6%，宏 F1 0.166。**

模型学会了"不管给什么，都判 Acetone"——塌缩到多数类。

原因：类别极不平衡 + 交叉熵等权 + 样本少参数多。

**不是数据不够，是"训练目标"和"评价指标"方向相反。**

---

## 4. 类间挤压：Acetaldehyde 为什么崩

看 2.1：

- **Ethanol 偏移最大（1.75σ），召回 0.96 —— 没事**
- **Acetaldehyde 偏移只有 0.77σ，召回 0.00 —— 全错**

如果"漂移大就崩"，该崩的是 Ethanol。

**真实机制是"类间挤压"：** batch2 里 Ethanol 样本从 90 涨到 164，分布变宽，把 Acetaldehyde 整个罩了进去。

> 原来两个班靠校服区分；现在 A 班人数翻倍、什么衣服都穿，把 B 班的人也罩住了。
> **不是 B 班的人变了，是判别的边界被挤掉了。**

**任何"分布漂移检测"都测不出这类问题**——它不表现为分布移动，而表现为**重叠度上升**。

唯一有效信号：**每类召回**。

## 5. 结论

| 项 | 结论 |
|---|---|
| 数据形态 | **按生产批次成块**，不是随机流 |
| 类内漂移 | ✅ 真实存在，0.33–1.75σ |
| 类别占比 | ✅ 剧烈变化（PSI 1.01），但这是排产，不是漂移 |
| 类间重叠 | ✅ Acetaldehyde 被 Ethanol 淹没 |
| 固定窗 + PSI | ❌ **前提不成立，必须改** |
| 重训 | ❌ 在 A 包上是负收益，需类别平衡才可能转正 |
| 单类失效信号 | ✅ 只能用每类召回，不能用预测占比 |

**最重要的一句话：**

> **A 包的"变化"大部分不是漂移，是排产。**
> 真正的漂移是"同一产品，这批和上批比，传感器读数变了"。

## 6. 可行方案（三选一）

### 6.1 方案 A：块感知窗口

**核心**：不按固定条数切窗，按"块边界"切。

```python
# 用预测标签的切换点近似块边界
if pred != last_pred:
    run_len += 1
    if run_len >= 5:        # 连续 5 条同类才算真的换块
        close_block(); open_new_block()
last_pred = pred
```

块内统计（同类别样本），块满 N 条才判一次。

**优点**：贴合数据形态；不需要真实标签；A/B/C 三包通用（轴承、发动机也是按实体分块）。
**缺点**：预测错会导致块切错；实现比现在复杂。

### 6.2 方案 B：大窗口 + 类内分桶

**核心**：窗口开到 500 条，统计时按预测类别分组，组内算 PSI。

**优点**：不依赖块检测；改动最小（一个常数 + 分组统计）。
**缺点**：500 条才判一次，发现晚；预测错会污染分组。

### 6.3 方案 C：类内长期漂移累计

**核心**：维护每个类别的历史特征均值和方差，新样本按预测类别归桶，比较桶内分布与历史。

**优点**：最鲁棒，天然适配块状。
**缺点**：改动最大；冷启动慢。

---

## 7. 方案权衡

| | A 块感知 | B 大窗 | C 类内累计 |
|---|---|---|---|
| 贴合数据形态 | ★★★ | ★★ | ★★★ |
| 实现成本（越低越好） | ★★ | ★★★ | ★ |
| 发现速度 | ★★★ | ★ | ★★ |
| 三包通用 | ★★★ | ★★★ | ★★★ |
| 答辩好讲 | ★★★ | ★★ | ★★ |

**建议：先做 B（保底），再上 A（正解）。**

理由：B 只改一个常数 + 分组统计，能快速验证"窗口变大后 PSI 是否不再爆炸"；A 要动 `src/main.py` 循环结构，需走规则 B 备案。

## 9. 官方模型上能改什么，代价多大

### 9.1 硬约束

`checkpoint.npz` 里存着 `w1 / b1 / w2 / b2 / feature_mean / feature_std`。

后两个是标准化参数，写死在文件里，`train.py` 有测试禁止改
（`tests/test_baselines.py::test_validation_cannot_change_baseline_standardization`）。

**所以「改标准化」不能改 checkpoint，只能在 `predict.py` 里套一层。**
`predict.py` 是我们自己写的，想加什么都可以。

结构上限（`baselines/model.py`）：`1 <= hidden <= 128`，参数量 `< 100000`。

### 9.2 可动项清单

| 层 | 具体动作 | 改哪里 | 算力代价 | 数据要求 | 风险 | 实测过 |
|---|---|---|---|---|---|---|
| ① 预测预处理 | 用当前批重估 mean/std | `predict.py` | **0 训练，<1 ms** | 无 | 类别构成偏时被污染 | ❌ |
| ② 输出偏置 | `logits += bias`（等价调先验） | `predict.py` | **0 训练，<1 ms** | 无（可自适应） | bias 怎么定 | ❌ |
| ③ 类别加权微调 | `loss` 按 `1/n_c` 加权 | `train.py` | 0.9 秒/epoch | 需要带标签 | 仍可能塌缩 | ❌ |
| ④ 普通微调 | `--from-baseline` | `train.py` | 0.9 秒/epoch | 需要带标签 | **实测负收益** | ✅ |
| ⑤ 改结构 | hidden 32→128 / 加层 | `model.py` | 18 秒 | — | 过拟合；加层不能 resume | ❌ |

### 9.3 实测代价（A 包，`C:\Python311`）

| 动作 | 耗时 |
|---|---|
| 重估标准化 | < 1 ms |
| 调偏置 | < 1 ms |
| 微调 1 epoch（445 条） | 0.9 秒 |
| 完整重训 20 epoch | ~18 秒 |
| 评测预算 | 21600 秒 |

**算力全加起来不到 1 分钟，真正的代价是「判断该不该动」。**

### 9.4 为什么「动」很危险（实测）

| 动作 | A 包宏 F1 |
|---|---|
| **什么都不做（冻结）** | **0.704** |
| 微调 100 条 | 0.520 |
| 微调 300 条 | 0.340 |
| 微调 800 条 | **0.166** |

**单调变差**。原因：交叉熵不区分类别大小，532 条 Acetone 压倒 5 条 Toluene，
模型直接塌缩到「全判 Acetone」（准确率 0.996、宏 F1 0.166）。

**因此 ③ 类别加权是唯一可能同时解决「漂移」和「不平衡」的微调方式。**

### 9.5 建议顺序

1. **① 标准化重估**——零成本，针对 f041 的 11.46σ 偏移，可能是最大单点收益
2. **③ 类别加权微调**——治塌缩
3. **② 偏置**——作为前两者之后的补救，不做主力

### 9.6 与 TTA 的关系

本轮「在 `predict.py` 里用当前批重估统计量」**就是 TTA 的合法形态**——
不需要 BN 层、不需要梯度、不需要标签。

之前讨论「逻辑回归做不了 TTA」，指的是「改中间层表征」那一类；
**改输入统计量这一路，在官方模型上完全可行**，而且官方 baseline 是 1 层 tanh MLP，
在 `predict.py` 里手写一层标准化等价于给它加一个 BN。

## 10. 距离信号：要在模型自己的坐标系里量

### 10.1 缘起

用户提出一个直觉（未学过机器学习）：

> 数据是高维空间的点，同种气体挨得近，相当于六片区域；换一批数据后点会落到离六片区域都远的地方；
> 原模型只是找最近的区域输出标签。

方向正确，但**在原始 128 维空间里量距离完全不 work**，换成模型隐层就成立了。

### 10.2 两个空间对比

探针脚本：`.team/_peek_gas_geometry.py`（原始 128 维）、`.team/_peek_dist_signal.py`、
`.team/_peek_dist_hidden.py`（隐层 32 维）。均为一次性只读脚本，可删。

| 指标 | 原始 128 维 | **模型隐层 32 维** |
|---|---|---|
| 最近中心分类准确率 batch1 | 0.701 | **0.964** |
| 最近中心分类准确率 batch2 | 0.544 | **0.875** |
| 区分 batch1/batch2 的 AUC（d_min） | 0.7324 | **0.8618** |
| 识别「这一条判错了」AUC（batch1） | 0.3674（反向） | **0.886** |
| 识别「这一条判错了」AUC（batch2） | 0.5441（随机） | **0.712** |

参照：官方 MLP 自身 batch1 0.973 / batch2 0.879。
**隐层最近中心分类器（0.875）几乎追平 MLP 本体（0.879）。**

### 10.3 为什么原始空间不行

- 128 维里真正有用的只有少数几维（f041 等），其余是噪声；
- 等权欧氏距离被噪声维度淹没（维度灾难）；
- MLP 学的是「在少数方向上加权划边界」，不是「等权量距离」——**两套几何不相关**。

对照证据：batch2 中 Ethanol 平均 d_min = 118.33（极远）但正确率 0.96；
Acetaldehyde 平均 d_min = 8.72（很近）但正确率 0.00。

### 10.4 为什么隐层成立

`hidden = tanh(x @ w1 + b1)` 的 32 维输出，就是模型「看世界」的坐标系。
在这里量距离，等价于用模型学到的度量。

### 10.5 能测什么，不能测什么

| 信号 | 能测 | 不能测 |
|---|---|---|
| 隐层距离（逐样本） | 单条样本「陌生」、批次是否变了 | **整类搬家**（Acetaldehyde 全错但距离 2.52，比 Ethanol 3.11 还近） |
| 每类召回（需标签） | 整类失效 | 单条样本 |

**两者必须一起用**：个体级用距离，类别级用召回。

### 10.6 计划接入（明天实现）

给 `evidence` 增加两个字段：

- `hidden_dist_mean`：当前窗口内各样本「到最近类中心的隐层距离」的均值
- `hidden_dist_p95`：95 分位（抓极值；均值容易被极端样本拉爆——batch2 窗 2 均值 185.52）

实现要点：
1. 类中心用**训练集**的隐层均值预计算，随 checkpoint 一起存（合法，训练集公开）；
2. `predict.py` 每次 forward 顺带拿到隐层，成本 0；
3. 阈值待定：建议先用 batch1 的 p95 做基线，超过 1.5 倍报警；
4. 用途优先级：① 批次陌生度告警 ② 高风险样本不参与重训 ③ 漂移确认。
