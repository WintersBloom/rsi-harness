## 一个必须注意的坑

`experiments.md` 里的数字（如 F1 0.8208、C 段 0.465）来自**原型阶段的自构造数据流**，与官方三包（A 0.7210 / B 681.16 / C 50.93）**完全不可比**——那时候官方数据包还没发布。

作品文档开头有一张「哪些数字来自哪里」的对照表，每个数字都标了来源与能否横比。

## 复现

```bash
git clone https://github.com/WintersBloom/rsi-harness
cd rsi-harness
docker build -f Dockerfile -t zhixun-harness:1.3 .
# 三包验证（需要官方 public/train.jsonl 与 validation.jsonl）
python tools/verify_packs.py --checkpoints harness/checkpoints_trained
```
