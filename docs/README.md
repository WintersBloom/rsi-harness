## 预研阶段（2026-11-06 至 11-10，旧系统）

> **读这几份前请先知道**：官方数据包 11-10 才发布。在那之前我们用自己构造的工业漂移流（`src/simulate_drift.py`）建了一套完整闭环原型——数据窗、在线监测、在线决策、回滚。官方包到手后发现形态不同（训练集/验证集跨批次、推理期零状态），五环整体上移到训练轮。

> **所以这几份里的绝对数字（如 F1 0.8208）不能与官方三包的结果横比。** 它们的价值是"方法论在数据到手前已经跑通一遍"，以及那批否定结论。
