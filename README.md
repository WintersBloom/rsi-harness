## 三、三十秒跑通

```powershell
docker load -i dist/zhixun-harness-1.3.tar
docker run --rm --network none -i zhixun-harness:1.3 < inputs.jsonl > outputs.jsonl
```

输入一行一个 JSON：`{"inputs": {...}}`。**不需要 `task` 字段**——路由靠 `inputs` 的形状（含 `settings` → C；`features` 是对象 → B；`features` 是长度 128 的数组 → A），已用三包全量 1244 / 1679 / 23049 条验证零误判。

输出一行一个 JSON：分类 `{"outputs":[{"label":"...","score":0.98}, ...]}`（**按类别固定顺序排列，不是按分数排序**），回归 `{"outputs":{"value":123.4}}`。

实测（容器内、`--network none`）：A 1244 行 0.74 s、B 1679 行 0.44 s、C 23049 行 2.20 s。

## 四、这个系统在做什么

平台不给即时标签（`baselines/predict.py:1` 写着 "no model execution hooks"，官方测试里只要输入带 `RUL` 字段就直接抛错），推理进程是**零状态的纯前向**。所以"自进化"不在运行时发生，而在**训练轮**发生：

```
每一轮 → 诊断当前权重错在哪 → 决定改什么（或不改）
        → 训练 → 在验证集上判一次 → 变好才采纳，变差就回退 → 记账
```

**十轮的结果：A 有 6 次回退、B 有 6 次全回退、C 有 4 次回退。** "动了不如不动"不是失败，是这套判据在起作用——B 包六个动作全是坏的，系统一次都没采纳，最终保持官方权重，这是正确结果。

镜像里只有三个 `.py` 和三个 `.npz`（合计 0.19 MiB 权重）。**没有监测、决策、回滚**——这是合规要求，不是缺失：`TRAINING_GUIDE.md:32` 禁止验证集参与拟合任何统计量，`predict.py` 逐行无状态没有钩子。校赛阶段"自进化"的证据在记录里，不在运行时行为里；企业赛有工作区、每轮下发新数据，五环才真正跑在评测路径上。

## 五、诚实边界

- **A 包的 Acetaldehyde 恒为 0.0000**。不是没调，是换批后它与 Ethanol 的相对位置**翻了向**（跨批次二分类 AUC 0.1137，取负才 0.886；同批次内部 5 折 AUC 0.9939）。在"验证集不得参与拟合任何统计量"的红线下，方向翻转无法恢复。五组重平衡 + 六种救法全部确认（`docs/a_acetaldehyde.md`）。
- **B 包没有增益**，如实报 0。
- **C 包的 −3.66%** 十轮里六次接受四次回退，第 8–10 轮已见底，没有继续调（在同一份公开验证集上反复挑就是刷分）。
- **归一化增益 G 算不出分母**（官方没定义"阶段"）。我们不自造口径，只报绝对增益与单位成本增益。
- **A 包 +0.70pp 不构成"提升"**。作品文档、答辩材料、本文都写的是"在噪声带内"。

## 六、我们试过并且失败的东西（都有复现脚本）

| 尝试 | 结果 | 位置 |
|---|---|---|
| TTA 三种变体（熵最小化 / 标准化重估 / 伪标签） | 动权重只换 F1 假涨、AP 不动；标准化重估 −3.1pp | `docs/tta_probe.md` |
| 类别加权 / 过采样 / focal（救 Acetaldehyde） | 全部无效，跨批次 AUC 0.1137 是方向问题 | `docs/a_acetaldehyde.md` |
| 多模型集成（r01–r08 概率平均） | 全部更差（等权 −5.49pp），因累积训练已把历史压进最新模型 | `tools/exp_ensemble.py` |
| 评估门（变差就回滚）用于企业赛形态 | 把八轮均值从 **0.705 拖到 0.574** | `docs/作品文档.md` 第六节 |
| 用公开验证集调类别权重 / 输出偏置 | 拒绝，理由见 `docs/作品文档.md` 第四节 | — |
| 大模型当决策者（27B，官方 A 包） | **−8.07pp**（0.7256 → 0.6403），更保守、把该重训的改判成校准 | `docs/LLM驱动_官方数据实测.md` |
| 无标签距离信号（隐层 32 维到类中心） | 陌生度上有效（batch2 中位距离 1.089→2.341），但**错误定位失败**：氨气最陌生却 100% 判对、乙醛全错只排第三 | `docs/a_embedding_distance.md` |

这些否定结论都写进了报告，因为它们本身就是"该不该动"这个判断的证据。

## 七、企业赛形态的模拟（八轮滚动）

用原始数据的十个批次模拟"每轮下发一批新数据"：训练=已见批次，测=下一批未见。

| 配方 | 八轮均值 | 相对冻结 |
|---|---|---|
| 冻结（只见过 batch1） | 0.3859 | — |
| **累积全部历史** | **0.7050** | **+31.91pp** |
| 只用最近两批 | 0.6745 | +28.85pp |
| 只用最新一批 | 0.5910 | +20.51pp |

**没有灾难性遗忘**（445 条时 0.5976 → 9066 条时 0.6946）。但这不是提交预期——冻结臂只见过 batch1、天然吃亏，且这组实验**只做离线验证，不参与任何提交权重**（batch3–10 很可能就是隐藏测试流，绝不反向调参）。

## 八、边界与没做到的

1. **只在官方验证集上验证过**。隐藏测试流没有答案，我们的所有数字都是 batch2 上的。
2. **"越用越会调"没有证明**。只有一条十轮链，凑不出"同类漂移反复出现、恢复轮数递减"的重复事件。我们做到的是"在合适时机停手"，不是"进化"。
3. **数据喂入方式未确认**。假设是逐行 JSONL 走 stdin（`predict.py` 用 `for line in sys.stdin`，`--idle-exit` 默认 0 即读到 EOF）。若平台一次性写完再关闭，行为一致；若只写不关，会一直等——已向组委会确认。
4. **`model` / `model_source` 两栏无对应选项**。平台下拉只有两个 Qwen 型号，没有"不使用大模型"。我们选 `base`（官方原版权重、未微调）并在 `docs/作品文档.md` 第零节列出三条可核对的反证；已向组委会提问，得到答复会重填。
5. **B/C 没有做结构性改造**。改结构会切断 `parent_checkpoint_sha256` 的父子链，等于放弃"续训"的叙事。
